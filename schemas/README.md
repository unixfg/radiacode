# Vendored interchange schemas

- `n42-2012.xsd` is the ANSI N42.42-2011 schema version 0.0.54 dated
  2012-02-01, vendored from the SpecUtils validation fixtures at
  <https://github.com/sandialabs/SpecUtils/blob/master/unit_tests/test_data/schema/n42.xsd>.
  SpecUtils is distributed under LGPL-2.1-or-later.
- `npes-v2.schema.json` is the NPESv2 Draft 7 JSON Schema vendored from
  <https://github.com/OpenGammaProject/NPES-JSON/blob/main/schema/npes-2.schema.json>.
  NPES-JSON is distributed under GPL-3.0.

The exporter test suite validates representative output against these files.
